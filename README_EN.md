# ShudaoLe · Textbook Downloader

> **This repository contains no textbook files — it only provides a downloading tool.**

> **书到了 (ShudaoLe, "The Books Have Arrived")** — one-click official textbook downloader for China's Smart Education platform.

[简体中文](README.md) | **English**

A command-line + web-UI tool for downloading textbook PDFs from China's National Smart Education Platform for Primary and Secondary Schools (https://basic.smartedu.cn).

> **📌 Project status: feature-frozen, maintenance mode.** Since v1.5.0 no new
> features will be added; only fixes for platform-caused breakage. If the
> platform's catalog API, PDF endpoints, or auth flow change, the tool reports
> a clear error instead of failing silently — please report such cases to
> [Issues](https://github.com/tau625/ShudaoLe/issues).

## Download & Install

| Platform | How |
|---|---|
| Windows | Download `ShudaoLe-X.Y.Z-windows-x64.zip` from [Releases](https://github.com/tau625/ShudaoLe/releases/latest), extract, double-click `书到了.exe` |
| macOS (Apple Silicon) | Download `ShudaoLe-X.Y.Z-macos.zip`, extract, run `xattr -cr 书到了` in a terminal (removes the quarantine attribute), then `./书到了` |
| Linux (x64, glibc ≥ 2.35) | Download `ShudaoLe-X.Y.Z-linux-x64.tar.gz`, extract, `chmod +x 书到了 && ./书到了` |
| Any platform (run from source) | Clone this repo → `pip install -r requirements.txt` → `python smartedu_downloader_gui.py` (web UI) or `python smartedu_downloader.py` (CLI) |

> Notes for non-Windows platforms: "one-click token fetch" works on all three platforms (it auto-detects the system Edge/Chrome);
> the "Browse…" directory picker needs `zenity` on Linux (native on macOS) — you can also just type the path manually.
> The macOS build is unsigned; the first launch requires bypassing Gatekeeper. Linux builds are made on Ubuntu 22.04.

## Requirements

- **Python 3.8+** (uses `requests`; `tqdm` is optional for progress bars)
- **No Node.js needed**: the one-click token fetch is pure Python (drives the system
  Edge/Chrome via the Chrome DevTools Protocol).

Install dependencies:

```bash
pip install -r requirements.txt
```

> **About the one-click token fetch**: `auto_fetch_token.py` uses only the Python standard
> library (a hand-written WebSocket client that speaks to the CDP debugging port) to drive
> the system Edge/Chrome to open a textbook detail page and automatically capture the
> `x-nd-auth` header. It depends solely on an installed Edge/Chrome — **no** playwright
> browser binaries, no extra downloads, no Node.js.

## Packaging into an exe (recommended for distribution)

Package the whole tool as a **Windows executable** — recipients need **no Python, no Node.js**; extract and run:

```bash
pip install pyinstaller          # first time only
python make_icon.py              # first time only: generates app.ico
python -m PyInstaller build.spec  # or double-click build.bat (also produces the zip)
```

Outputs:

- `dist/书到了/` — the runnable folder (exe + runtime dependencies)
- `dist/书到了.zip` — distribution archive (generated automatically by build.bat)

> **Why a folder (onedir) instead of a single file (onefile)?** A onefile exe must
> self-extract to a temp directory on every launch — a behavior pattern that antivirus
> tools (Windows Defender, 360, …) readily flag as malicious. The onedir layout eliminates
> the self-extraction step, drastically reducing false positives and speeding up startup.
> Zipping the folder keeps distribution just as easy.

> **Zero dependencies**: the Python runtime is bundled inside the exe, and the token-fetch
> logic is integrated into the exe process itself (no external Python subprocess).
> The only thing the target machine needs is **Edge, which ships with Windows 10/11** —
> double-click the exe and everything works, including the one-click token fetch.

## I. Web UI (recommended — full feature set)

```bash
python smartedu_downloader_gui.py                # default port 8765, opens the browser automatically
python smartedu_downloader_gui.py --port 9000    # custom port
python smartedu_downloader_gui.py --no-browser   # don't auto-open; visit http://127.0.0.1:8765 manually
```

The UI listens on `127.0.0.1` only — it is never exposed to the network.

> **Only one instance may run at a time**: if ShudaoLe is already running, launching it
> again simply focuses the existing window and shows a notification instead of starting a
> second process. This prevents multiple processes from silently sharing the same port,
> which would scatter requests randomly (symptoms: clicks doing nothing, progress frozen).
> If port 8765 is taken by **another program**, ShudaoLe automatically picks a free port
> (reflected in the URL it opens).

Features:

- Browse the platform's textbook catalog by **phase / grade / subject / publisher / volume + keyword** (the dropdown order mirrors the search path: pick grade and subject first, then publisher and volume)
- **Cascading filters**: each dimension's candidate values are computed live, excluding that dimension's own current selection; you can freely switch within a dimension after choosing
- **Active-filter tags**: current filters shown as removable tags; clear one or all with a click
- **Empty-result guidance**: when nothing matches, the UI tells you exactly which filter to drop to recover how many results, with one-click relaxation
- Results sorted by **phase → grade → subject → publisher → volume**, so same-grade same-subject books cluster naturally
- Currently enabled publishers: **PEP family (人教版 / 统编版 / 人教鄂教版) and 沪教版 (Shanghai Education Press)**; others hidden — the publisher dropdown offers a "select whole family" level plus an "exact label" level (see the end for extending)
- Check multiple textbooks into a download list with live progress
- "Open file / open containing folder" to locate finished downloads
- A "one-click auto token fetch" button (opens a browser; after you sign in with QR code or phone number, the token is captured automatically — no Node.js)

### Getting a login token (required for PDF downloads)

The platform requires login for PDF downloads; anonymous requests usually get a **401**. Any of these three methods works:

1. **"One-click auto token fetch" in the web UI** (opens a browser automatically; sign in once — no Node.js needed)
2. Manual copy: log in on the platform → F12 → **Network** → filter `pdf` → click a `pdf` request → copy the full `x-nd-auth` value from **Request Headers**
3. Save the token to `token.txt` — the tool prefers the user config directory (`~/.config/shudaole/token.txt`, on Windows `%USERPROFILE%\.config\shudaole\token.txt`) and reuses it automatically; **a `token.txt` sitting next to the program (as in older versions) is still read**, so no manual migration is needed

## II. Command line

### Download by link / contentId

```bash
# Single: pass a full detail-page URL or a contentId
python smartedu_downloader.py "https://basic.smartedu.cn/tchMaterial/detail?contentType=assets_document&contentId=xxxx&catalogType=tchMaterial&subCatalog=tchMaterial"

# Batch: multiple arguments
python smartedu_downloader.py <link-or-id-1> <link-or-id-2> -o "D:/textbooks"

# Batch: read from a text file (one link or ID per line)
python smartedu_downloader.py -f links.txt -o ./downloads

# No arguments -> interactive mode; paste multiple lines, end with an empty line
python smartedu_downloader.py
```

### Search and download by filters

No links needed — filter the catalog directly:

```bash
python smartedu_downloader.py --phase 小学 --subject 语文 --grade 一年级 --list-only   # list matches first
python smartedu_downloader.py --phase 小学 --publisher 人教版系 --subject 数学 --all -o ./downloads  # download all matches
```

Common filter parameters (all dimensions except `--publisher` use **substring matching** — e.g. "统编" matches "统编版"):

| Parameter | Meaning | Example values |
|------|------|--------------|
| `--phase` | School phase | 小学 (primary) / 初中 (junior high) / 高中 (senior high) |
| `--grade` | Grade | 一年级, … (grade 7 = 七年级) |
| `--subject` | Subject | 语文 / 数学 / 英语 / 科学, … |
| `--publisher` | Publisher | Group name `人教版系` (= 人教版 + 统编版 + 人教鄂教版), exact label `统编版`, or shorthand `人教` |
| `--volume` | Volume | 上册 / 下册 |

> The platform labels PEP-family Chinese textbooks as "统编版", math as "人教版", and
> science as "人教鄂教版" — so use `--publisher 人教版系` to grab the whole PEP family,
> or an exact label for one specific line.

Output and token options:

```bash
-o, --output <dir>       Download directory (default ./downloads)
--token <token>          Explicit x-nd-auth token
--retries <n>            Retries on failure (default 3)
--timeout <seconds>      Request timeout (default 30)
--no-save-token          Don't persist the token to token.txt when entered interactively
--flat-name              Name files by plain book title (default: structured naming)
```

### File naming rules

Structured naming is the default, producing filenames like:

```
小学语文_统编版_一年级上册.pdf
小学数学_人教版_一年级上册.pdf
小学聋校道德与法治_统编版_一年级上册.pdf      # Special-education schools (deaf / blind / intellectually disabled) get their own prefix
小学道德与法治_统编版_五·四学制一年级上册.pdf  # 5·4 and 6·3 academic systems are separate series
初中体育与健康_人教版_八年级全一册_教师用书篮球.pdf  # Distinguishing info not in metadata fields is appended
```

The template is `{phase}[{special school}]{subject}_{publisher}[_{academic system}]_{grade & volume}[_{distinguisher}]`. Book-title information that lives outside the publisher/grade fields (teacher's edition, numbered notation, basketball, student activity handbook, …) becomes a **distinguishing suffix**, preventing e.g. "PE teacher's edition · basketball" from overwriting "· soccer". Missing segments are omitted automatically (no dangling underscores); if everything is missing, the cleaned book title is used.

- Add `--flat-name` on the CLI to fall back to plain-title naming (historical behavior).
- In the web UI, tick "纯书名命名" in the download-task card to switch back.

> When detail metadata is incomplete, special-school and academic-system markers are
> recovered from the title text, so special-education and 5·4-system textbooks never
> collide with regular ones.

### Title normalization

Raw platform titles are wildly inconsistent (redundant prefixes, mixed `•`/`·` separators, stray spaces inside Chinese text, inconsistent academic-system spellings). Catalog browsing and result display normalize them first:

- Carrier prefixes like "（根据2022年版课程标准修订）", "义务教育教科书", "普通高中教科书" are stripped
- `•` is unified to `·`; stray spaces between Chinese characters are removed
- Academic systems are normalized to "五·四学制" / "六·三学制"; deaf/blind/special-education markers are kept as title prefixes

The raw title is preserved in the `title_raw` field — both spellings remain searchable.

## III. FAQ

- **401 / 403**: no valid token, or the token expired. Re-fetch `x-nd-auth`. If **every** detail-JSON endpoint returns 403, the resource has been delisted by the platform.
- **Stale catalog**: catalog data is cached in `catalog_cache.json` next to the script (expires after 7 days); delete the file to force a refresh.
- **Port in use**: the GUI switches ports automatically, or pass `--port`.
- **Garbled Chinese paths (old versions only)**: the tool now ships UTF-8 console and directory-picker fixes; if you still see issues, update to the latest release.

## Enabling more publishers / phases

Publisher groups `PUB_GROUPS`, phase scope `SUPPORTED_SCOPE`, and UI dimensions `ENABLED_DIMS`
are defined at the top of **`smartedu_downloader.py`** and shared by the CLI and the web UI,
so there is exactly one place to change.

To enable more publishers (e.g. 北师大版 BSD, 教科版 …), add a line to `PUB_GROUPS` and restart the GUI:

```python
PUB_GROUPS = {
    "人教版系": ["人教版", "统编版", "人教鄂教版"],
    "沪教版":   ["沪教版"],
    "北师大版": ["北师大版"],      # ← new: "北师大版" appears in the UI immediately
}
```

Rendering rules for groups:

- A group with **more than one** label renders as two levels: "group (select the whole family)" plus the exact labels (precise selection)
- A group with **exactly one** label becomes a single top-level option — no redundant nesting

`SUPPORTED_SCOPE` restricts which values of a dimension are open (e.g. `"phase": ["小学"]`);
out-of-scope values show as "not yet available" and are unselectable. If a dimension has
exactly one open value, it is auto-selected on first load (derived from `DEFAULT_FILTERS`)
to avoid an initial screen with thousands of mixed results.

> The CLI is **not** restricted by `PUB_GROUPS` / `SUPPORTED_SCOPE` — `--publisher` accepts any label directly.

## Development Notes (read before repackaging)

This section records **real pitfalls hit during packaging**. If your local environment is
ever lost, read this first after cloning — it saves hours of re-debugging.

### 1. `dist/` / `build/` refuse to be deleted

Some environments (e.g. AI coding tools with a "safe delete" hook) redirect `rm` /
`os.remove` / `shutil.rmtree` / PowerShell `Remove-Item` to a recycle-bin tool. That tool
mangles **non-ASCII (Chinese) paths**, fails to delete, and then refuses to fall back to a
direct delete — the directory never goes away.

**Fix**: bypass those commands and call the .NET API directly:

```powershell
[System.IO.Directory]::Delete("D:\path\to\dist\书到了", $true)   # directory
[System.IO.File]::Delete("D:\path\to\dist\书到了.zip")            # file
```

### 2. Version info in exe properties is all empty

- **Pitfall 1**: `EXE(version=...)` takes the **path string of the version file**, not its
  contents (PyInstaller calls `open(filename)` itself). Passing the contents raises
  `FileNotFoundError`.
- **Pitfall 2 (the real culprit)**: the `StringTable` language code in `version_info.txt`
  must match the `VarFileInfo` `Translation`. This project uses Translation `[1033, 1200]`
  (English), so the StringTable key must be `040904b0` (English 0x0409). Writing `080404b0`
  (Chinese 0x0804) misaligns the resource tables and Windows reads every field as empty —
  **while the build log still happily prints "Copying version information to EXE"**, which
  is deeply misleading.

### 3. Multi-instance port conflict (once masqueraded as "Chinese filename broke it")

`ThreadingHTTPServer` defaults to `allow_reuse_address=1`, so double-clicking the exe again
lets a second process **silently share port 8765** — no error, no prompt, but requests get
scattered across instances: clicks do nothing, progress bars freeze. **This is not about
the Chinese filename.**

The fix (in `smartedu_downloader_gui.py`) keeps three pieces — preserve them when editing:

| Component | Purpose |
|------|------|
| `LocalServer.allow_reuse_address = 0` | Exclusive port; a duplicate launch fails loudly instead of sharing silently |
| `_probe_existing()` | Probes for a running instance before starting; reuses its window + notifies + exits |
| `_notify()` | Windowed mode has no console — a message box is the only visible feedback |

`_probe_existing()` bypasses the system proxy to hit `127.0.0.1` directly and only trusts
this program's characteristic response, so it never mistakes another app on the same port
for itself.

### 4. Three traps when testing a local server (they produce fake failures)

1. **Bypass the system proxy**: `urllib.request` honors system proxy settings; with a proxy
   running, requests to `127.0.0.1:8765` get intercepted and return **502**. Use
   `urllib.request.build_opener(urllib.request.ProxyHandler({}))`.
2. **Detach from the process group**: start with
   `subprocess.Popen(..., creationflags=DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP)`,
   or the child dies with the test command and the next command sees `ConnectionRefused`.
3. **Don't `tasklist | grep <Chinese process name>`**: Chinese text mangles in pipes, the
   grep always fails, and you'll wrongly conclude the exe never started. Use
   `tasklist /FI "PID eq <pid>"` instead.

### 5. Miscellaneous conventions

- Install deps with `python -m pip install`, **never bare `pip`** (it may point at another Python).
- Token fetching is integrated into the GUI process (`auto_fetch_token.run_token_fetch`);
  **do not revert to subprocess with an external Python** — that would force every user to install Python.
- Filter-dimension rules live at the top of `smartedu_downloader.py`, shared by CLI and GUI.
- When adding a dimension-order table, remember to register it in `DIM_ORDERS`.

## Versioning & Release Conventions

Semantic versioning (`major.minor.patch`), judged by **user-visible impact**:

| Level | Trigger | Example |
|---|---|---|
| Major +1 | Breaking changes or major trade-offs: dropping platform support, incompatible file-naming changes, removing a core workflow, complete UI redesign | 1.x → 2.0.0 |
| Minor +1 | New capabilities without affecting existing usage: new features, new platforms, chunky UI rework | Cross-platform support (1.2.0) |
| Patch +1 | Fix-only: bug fixes, security hardening, CI/build-chain adjustments, dependency & doc updates | Local-server security hardening (1.1.1) |

- Pre-releases use `vX.Y.Z-beta.N` and are marked as pre-release; urgent security fixes ship as patch releases
- Fixed release routine: bump `version_info.txt` (the single source of truth for the version) → sync the fallback version in `smartedu_webui.html` → commit → push the `vX.Y.Z` tag; CI builds all three platform artifacts and attaches them to the Release
